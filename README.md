# Claude Chat History
Tool for managing chat history on AI chat sessions decoupling from a local environment. 

> [!NOTE]
> This is an AI driven and created project on purpose. 


## Abstract
By default claude code (CLI) keeps its chat history centralized locally to the machine you are currently running the chat session on. This can make transparancy or re-engagement difficult for working on multiple machines. This repos contains notes and chat history utilities to pivot to keeping this history locally to the folder your working such as a project repo.
